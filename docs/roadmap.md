# 范围

## 初版（一次交付，功能完整）

- 模板编辑器：字段增删改、拖动排序、类型/上限/颜色/默认值，模板导入导出 JSON，内置通用模板（覆盖 6 种字段类型）
- ```fs 全量快照解析与容错：截断丢弃、解析失败静默沿用、值类型推断、未知键收编/忽略
- 卡片式侧栏：角色名卡片、卡头摘要、点击展开/折叠、折叠状态按聊天记忆、群聊多角色一卡一角色
- 点值即改：bar 拖动/输入，chip/text/tag/list/check 各自的编辑态
- 字段锁定：锁定字段忽略 AI 更新，手改不受影响
- 回注双轨：generate_interceptor 自动注入、{{fs_state}} 宏，可全关
- 随角色卡存储：模板与状态经 writeExtensionField 写入/载入角色卡
- swipe 与消息编辑的状态回退（MESSAGE_SWIPED / MESSAGE_EDITED 重解析）
- 隐藏正则自动注册开关；诊断面板（最近解析结果、失败计数、清空本聊状态）

## 实验项（初版之后想做再说，不承诺）

- delta 输出：AI 只写变动键，需要定期全量兑底，小模型容易写漏
- 独立 LLM 抽取：generateQuietPrompt + structured outputs，用便宜模型更新状态
- 模板分享：模板导出单文件，收集社区模板
- 世界书 md→json 构建脚本（沿用 Markdown 源文件构建世界书 JSON 的模式）
