# FreeStatus 输出协议与提示词

本页内容可直接粘贴使用。设置面板的「复制协议提示词」按当前模板生成同样的条目，本文以内置通用模板为例给出定稿样板。

## 1. ` ```fs ` 代码块规范

AI 在每条回复的最末尾输出一个 ` ```fs ` 代码块，内容为单个 JSON 对象：

````
```fs
{"_char":"玲","affection":45,"mood":"平静","condition":"一切正常","impressions":{"老师":50},"items":["手机","钥匙"],"injured":true}
```
````

规则：

1. 宁缺勿滥：状态栏只反映角色当前真正有的状态，绝不为了凑满而输出。没有的状态（例如角色并不恐惧、不疲劳）就不要输出对应字段，也不要用 0 或空值占位。
2. 有值快照：只输出当前有值的 key；没有值、不适用或剧情未涉及的字段省略该键，省略即视为清空（此处 `trust` 省略表示当前无值）。数值字段只在明显存在该状态时给出，处于基准或无明显变化的状态不输出；布尔字段只在成立时输出。
3. `_` 前缀键是元数据：`_char` = 状态归属角色（单聊可省略，缺省为 `{{char}}`）。
4. 键名必须与模板声明完全一致（协议提示词已列出清单）；上轮有值且本轮仍有意义的字段继续输出。
5. 严格合法 JSON：双引号、无注释、无尾逗号、无 markdown 说明文字。
6. 数值不带单位与千分位（`45` 而非 `45%` 或 `1,045`）。

状态栏只显示有值字段：AI 省略的键不渲染；想手动给空字段赋值，用卡片底部「显示空字段」开关。手动改过的字段自动锁定，不受后续快照影响。

## 2. 世界书常量条目（通用模板版 · 直接粘贴）

位置：世界书新条目 → 🔵 Always Insert → 位置 `@d 0 (system)`（或预设的聊天后指令）。此条目在关闭「自动注入协议规则」时使用；开着自动注入时无需世界书。换模板后从设置面板重新复制即可，无需手改。

```text
【FreeStatus 状态协议】
每条回复的最末尾必须输出一个 ```fs 代码块，内容只含一个 JSON 对象（不要解释、不要 markdown 说明），描述 {{char}} 当前状态。只输出当前有值的字段，字段与键名如下：

- "affection"：好感，0-100 整数（无该状态时省略，不要用 0 占位）
- "trust"：信任，0-100 整数（无该状态时省略，不要用 0 占位）
- "mood"：心情，2-4 字短语
- "condition"：状态，一句话
- "impressions"：印象，对象，键=对象，值=0-100 程度
- "items"：随身物品，字符串数组
- "injured"：受伤，true/false（仅成立时输出）

规则：
1. 宁缺勿滥：状态栏只反映角色当前真正有的状态，不要为了凑满而输出。没有的状态（例如角色并不恐惧、不疲劳）就不要输出对应字段，也不要用 0 或空值占位。
2. 只输出当前有值的字段：没有值、不适用或剧情未涉及的字段省略该键；上轮有值但本轮已无值的字段也必须省略该键（省略即清空）。数值字段只在明显存在该状态时给出，处于基准或无明显变化的状态不输出；布尔字段只在成立时输出。
3. 上轮已有值且本轮仍有意义的字段继续输出，禁止无故丢弃；数值变化必须有正文情节依据，正文没体现的变化沿用下方「当前状态」里的值。
4. 输出示例（仅示意格式与省略方式，实际键集合按当前有值字段而定）：
```fs
{"_char":"{{char}}","affection":45,"mood":"平静","condition":"一切正常","impressions":{"老师":50},"items":["手机","钥匙"],"injured":true}
```
5. 严格合法 JSON：双引号、无注释、无单引号、无尾逗号。

当前状态：
{{fs_state}}
```

说明：

- 回注行：末尾 `{{fs_state}}` 是 FreeStatus 宏。若用自动注入（interceptor），删掉此行；若用宏，保留此行并在宏设置里确认 `fs_state` 已注册；若回注全关，把整行替换为「当前状态：（无）」。
- 规则 2 的 one-shot 示例比任何规则都管用，务必保留。
- 换模板后无需手改本文：设置面板「复制协议提示词」按当前模板重新生成字段清单。

## 3. 隐藏正则（正文不显示状态块）

插件默认在消息渲染时隐藏原始块（设置里的「隐藏消息中的原始状态块」）。想改用 ST 正则脚本托底，可新建一条（运行于「AI 响应」）：

| 项 | 值 |
|---|---|
| 查找（Regex） | ```` ```fs[\s\S]*?``` ```` |
| 替换（Replace） | （留空） |
| 作用范围 | AI 消息 |

- 别用「显示标签」功能，会把块内 JSON 也显示出来。

## 4. 回注格式

### 4.1 宏 `{{fs_state}}`

展开为紧凑状态串（只含 `inject: true` 的字段）：

```text
当前状态：好感=45，信任=30，心情=平静，状态=一切正常，印象={老师:50}，随身物品=[手机,钥匙]，受伤=否
```

用法：写进世界书/预设任意位置，位置完全由用户控制。

### 4.2 interceptor 自动注入

`generate_interceptor` 在每次生成前注入协议规则与当前状态（设置面板可开关、可预览注入文本）。开启协议注入时 AI 无需世界书即知道输出格式；状态暂无时会提示 AI 按剧情初始化。

## 5. 失败模式 FAQ

**Q：AI 回复被截断，` ```fs ` 不完整怎么办？**
A：解析层容错自动处理：括号不闭合/JSON 非法时丢弃本次、沿用旧状态，正文不受影响。内容过滤或长度上限都可能导致截断，建议关闭流式输出降低概率。

**Q：AI 忘输出状态块？**
A：状态不变，侧栏保持上一个值，不报错。若频繁发生，在协议条目加一句「即使数值未变化，每条回复也必须输出状态块」，或检查预设里是否有截断输出的正则。

**Q：数值乱涨/乱掉？**
A：三重防线：协议规则 1（变化须有正文依据，未体现沿用当前值）；回注提供当前值锚点（推荐开启）；字段锁定（🔒），对最敏感的值锁定后 AI 更新被忽略。

**Q：与预设的状态栏条目 / COT 冲突？**
A：关闭预设里已有的状态栏条目和思维链输出；同类状态栏扩展只留一个。

**Q：AI 输出了模板里没有的字段？**
A：正常显示在卡片「其他」分组（按类型推断渲染），点「收编」一键加入模板，或「忽略」不再显示。

**Q：某个字段一直不出现？**
A：AI 判断该字段无值时省略该键，状态栏相应不渲染，属正常行为。想手动给空字段赋值，点卡片底部「显示空字段 (N)」开关展开全部字段行；手动改过的字段会自动锁定，不被后续快照清掉，解锁后交还 AI 控制。

**Q：正文里出现了状态块文字（没隐藏）？**
A：检查设置里的「隐藏消息中的原始状态块」是否开启，或启用第 3 节的隐藏正则。

**Q：换聊天/换角色卡后状态错乱？**
A：状态按聊天隔离（`chatMetadata`），切换聊天自动重载；角色卡随卡存储需在设置面板手动「写入角色卡」，导入新卡后在设置里点「从角色卡载入」。

## 6. 「复制协议提示词」的生成逻辑（设置面板实现依据）

```
【FreeStatus 状态协议】
每条回复的最末尾必须输出一个 ```fs 代码块，内容只含一个 JSON 对象……只输出当前有值的字段，字段与键名如下：
{for 每个 field in 当前模板}
- "{key}"：{label}，{kind 对应约束描述}{max 上限}
{end}
规则：
1. 宁缺勿滥：没有的状态不要输出，也不要用 0/空值占位……
2. 只输出当前有值的字段……省略即清空……数值字段处于基准或无明显变化时也省略……
3. 上轮已有值且本轮仍有意义的字段继续输出……
4. 输出示例：
```fs
{每种 kind 取一个字段生成稀疏示例，值取 sample 或 default}
```
5. 严格合法 JSON……
当前状态：
{{fs_state}}
```

kind 约束描述映射：`bar`→「0-{max} 整数（无该状态时省略，不要用 0 占位）」、`chip`→「2-4 字短语」、`text`→「一句话」、`tag`→「对象，键=…值=…」、`list`→「字符串数组」、`check`→「true/false（仅成立时输出）」。字段的备注（可选 `note` 属性）会替代或补充默认描述（`chip`/`text`/`check` 的 note 替代默认文案，`bar`/`tag`/`list` 的 note 拼接进描述），生成时带入。
